# detection-lab

Wazuh + Sigma detections from my home SOC lab, each one tested with Atomic Red Team.
Built during Sprint-30, a 30-day hands-on security sprint.

| Folder | What's in it |
|---|---|
| `wazuh/` | Agent config snippets; custom rules (`local_rules.xml`) from Day 8 |
| `sigma/` | The same detections as portable Sigma rules (from Day 8) |
| `lab/` | Lab setup: Windows audit policy, AD lab notes |
| `attack-navigator/` | ATT&CK coverage layer (Day 24) |
| `reports/` | Pentest report PDF (Day 18) |
